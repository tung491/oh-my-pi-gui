### Required design changes recorded for Phases 2, 3, 5 and 8

1. **Sidecar supervisor (S7b, Phases 2/3).** Spawn each sidecar through a supervisor process (own session, child subreaper, parent-death signal) instead of directly; the supervisor relays stdio, SIGTERMs omp with a 5 s grace, then SIGKILLs every reparented orphan. Linux primitives: `setsid`, `prctl(PR_SET_CHILD_SUBREAPER)`, `prctl(PR_SET_PDEATHSIG, SIGTERM)`, omp in its own process group; the supervisor must never panic on a dead stderr pipe. macOS and Windows need equivalents (see counsel below). The agent's own SIGTERM cleanup does not kill external tool children, and stdin EOF makes it drain the running tool first.
2. **WebKit sandbox hook (S14, Phase 2 `webview.rs`).** Override `WebKitWebContext`'s GObject `constructed` once before `tauri::Builder`, enabling the sandbox on every context before its first process. No AppArmor rule is needed on Ubuntu 26.04.
3. **App identity (S11, Phase 5).** `app.enableGTKAppId: true` in `tauri.conf.json` and `glib::set_prgname(Some(APP_ID))` before GTK initializes.
4. **Voice capture (S4, Phases 2/4).** Replace `MediaRecorder` in `src/renderer/lib/voice.ts` with WebAudio PCM capture: an `AudioWorklet` module shipped as a Vite asset from the app origin (`'self'`), `ScriptProcessorNode` only as a capability fallback, one `Float32Array` accumulator feeding the existing `OfflineAudioContext` 16 kHz resample and PCM16 WAV encode; `getUserMedia` constraints and the `permission-request` → allow hook stay as designed. No new Rust channel, no `cpal` dependency: drop the cpal clause from Task 0.5 and the "dependency and channels from kongming's revision" clause in Phase 2 Task 2.1. Phase 8 must not add `gstreamer1.0-plugins-bad` as a dependency.
6. **Desktop entry (S11, Phase 8).** The Tauri bundler writes `{productName}.desktop` with `StartupWMClass={{exec}}`, which matches neither the `vn.io.vif.saiatlas` app_id nor the existing `vn.io.vif.saiatlas.desktop`; Phase 8 needs a `desktopTemplate` with `StartupWMClass=vn.io.vif.saiatlas` (or the identifier as the file basename), and the `.deb` `Depends` must add `bubblewrap` and `xdg-dbus-proxy` (WebKit treats a missing bwrap as fatal once the sandbox is enabled; the spike's .deb lists only `libayatana-appindicator3-1, libwebkit2gtk-4.1-0, libgtk-3-0`).
5. **Quick-entry height (S6, Phase 5).** The frameless bar reports 200 px inner height for a 168 px request; Phase 5 should size the bar from the measured minimum or set a GTK size request.

### Counsel (kongming)

Kongming was consulted once (autonomous, with the evidence above) and agreed with every measurement; its decisions, which I adopt for the record:

- **S4 → option (a)**, WebAudio PCM capture as design change 4, not `cpal` and not `gstreamer1.0-plugins-bad`: a distro plugin set an AppImage cannot guarantee, a lossy Opus round trip, and (as the rerun showed) still not a working recorder on this build. WebAudio capture is core engine code on WebKitGTK, WKWebView and WebView2, so the renderer keeps one voice path. The worklet matters over `ScriptProcessorNode` because it runs on the audio thread and survives long main-thread tasks (streaming markdown). Keep the `ScriptProcessor` fallback while Electron still ships. Echo cancellation on Linux is unchanged by the switch (the constraint acts on the track; `webrtcdsp` is absent either way).
- **S7b → keep the supervisor**, hardened for Phase 3: re-exec the same binary with a reserved argv before `tauri::Builder` runs (no second `externalBin`, invisible to the single-instance and deep-link plugins); use a dedicated control pipe whose EOF is the primary parent-death signal, because `PR_SET_PDEATHSIG` fires when the forking *thread* exits and tokio can retire that thread (keep PDEATHSIG as belt and braces); pass omp's NDJSON pipes straight through (dup2 in `pre_exec`) so the supervisor never relays frames and the S3/S7 numbers stay valid; sweep `ppid == self` orphans in passes until a pass kills nothing or 2 s elapse; exit with omp's status. Frozen topology: GUI → supervisor (`setsid`, `CHILD_SUBREAPER`, `PDEATHSIG=SIGTERM`, control pipe) → omp (own process group, inherited stdio) → tool children. Signals: SIGTERM to omp, 5 s grace, SIGKILL to omp's group, orphan sweep ≤ 2 s. Windows: a Job Object with `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE` held by the GUI, no supervisor (check that pi-natives does not spawn with `CREATE_BREAKAWAY_FROM_JOB`). macOS: the supervisor with the control pipe plus kqueue `EVFILT_PROC/NOTE_EXIT` on the GUI pid and a recursive `proc_listchildpids` snapshot taken before killing omp (orphans reparent to launchd there). Electron today has the same orphan hole (`sidecar.ts` spawns without `detached`), so S7b is an improvement, not parity. A `patches/omp` change making the agent kill tool children on SIGTERM is defence in depth only.
